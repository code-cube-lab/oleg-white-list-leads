# WHITE LIST — рабочая доска клиентов v5

Самодостаточный мобильный сайт Олега Михайличенко для поиска заказов на
видеомонтаж и AI-видео.

## Что внутри

- 100 новых проверенных карточек с рейтингом релевантности;
- персональный черновик отклика для каждой вакансии;
- отдельное окно с предыдущими 33 приоритетами;
- отдельное окно со всеми прежними 300 лидами;
- готовое описание и прайс для Profi.ru;
- три готовых объявления для Авито;
- лучшие подряды, пакетные предложения и список площадок.

## Локальный запуск

Сайт можно открыть напрямую через `index.html` или запустить простой сервер:

```powershell
python -m http.server 5178 --directory .
```

Затем открыть `http://localhost:5178/`.

## Пересборка

```powershell
python finalize_leads.py
python build_v5.py
```

`finalize_leads.py` отбирает 100 уникальных прямых видеоролей из проверенного
пула. `build_v5.py` читает прежнюю базу из `../board-v3/data.json`, сохраняет
предыдущие 33 приоритета и создаёт `data.json` и `index.html`.
