# WHITE LIST — рабочая доска клиентов

Самодостаточный мобильный сайт Олега Михайличенко для поиска заказов на
видеомонтаж и AI-видео.

## Что внутри

- свежие приоритетные вакансии с рейтингом релевантности;
- персональный черновик отклика для каждой вакансии;
- отдельный архив прежних 300 лидов;
- готовое описание и прайс для Profi.ru;
- три готовых объявления для Авито;
- лучшие подряды, пакетные предложения и список площадок.

## Локальный запуск

Сайт можно открыть напрямую через `index.html` или запустить простой сервер:

```powershell
python -m http.server 5178 --directory .
```

Затем открыть `http://localhost:5178/`.

## Пересборка

```powershell
python build_v4.py
```

`build_v4.py` читает прежнюю базу из `../board-v3/data.json`, добавляет новые
разделы и создаёт `data.json` и `index.html`.
