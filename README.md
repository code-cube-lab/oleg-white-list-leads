# WHITE LIST — рабочая доска клиентов v6

Самодостаточный мобильный сайт Олега Михайличенко для ручного поиска заказов
на видеомонтаж и AI-видео.

## Что внутри

- 300 новых уникальных лидов, проверенных 11 августа 2026 года;
- 90 вакансий HH.ru и Remote-job и 210 публичных Telegram-заказов;
- отдельный черновик отклика для каждой новой карточки;
- отдельные вкладки с прошлыми 100, прежними 33 и архивными 300 лидами;
- поиск, фильтр источников, рейтинг, кнопки «Отложить» и «Написал»;
- готовые материалы для Profi.ru, Авито и работы с подрядчиками.

Доска не отправляет сообщения автоматически. Перед откликом нужно открыть
исходную карточку и повторно проверить актуальность, бюджет и условия теста.

## Локальный запуск

Сайт можно открыть напрямую через `index.html` или запустить простой сервер:

```powershell
python -m http.server 5189 --directory .
```

Затем открыть `http://localhost:5189/`.

## Обновление данных

```powershell
python collect_new_leads.py
python collect_telegram_leads.py
python build_v6.py
```

Скрипты не дополняют список выдуманными карточками: сборка требует ровно 300
уникальных новых ссылок и сохраняет прежние подборки из `../board-v5/data.json`.
